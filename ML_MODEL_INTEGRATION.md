## 1. Overview & Architecture

The ML integration connects the AgriSurvey AI web platform with the specialized Maharashtra remote sensing and crop classification engine in `GM-ML-V2`.

```
[Web Application (React / TS)]
       │  (Coordinate: lat, lon, radius, 15-day periods)
       ▼
[Monitoring API Bridge]
       │
       ▼
[Remote Sensing Engine (cropsurvey)]
       │
       ├─► 1. STAC Scene Discovery (Earth Search AWS Sentinel-2 L2A)
       ├─► 2. Windowed COG Sub-pixel Extraction (10m / 20m aligned grid)
       ├─► 3. BOA Radiometric Calibration & SCL Cloud/Shadow Masking
       ├─► 4. 15-Day Maximum-NDVI Compositing
       ├─► 5. 7 Spectral Indices: NDVI, EVI, SAVI, NDWI, NDMI, NDRE, GCVI
       ├─► 6. 158-Feature Phenology Extraction (build_features)
       ├─► 7. LightGBM Inference + Isotonic Probability Calibration
       ├─► 8. Phenology Growth Staging & Anomaly Detection
       │
       ▼
[Persistent Storage (Supabase / Local MockDb Cache)]
       │
       ▼
[Farmer & Tahsildar Dashboards]
```

## 2. Feature Schema & Preprocessing

The model uses a strict 158-feature vector generated by `cropsurvey.models.features.build_features()`:

### A. Spectral and Radar Indices (7 Indices + 2 SAR)
1. **NDVI:** Normalized Difference Vegetation Index: `(NIR - Red) / (NIR + Red)` using Band 8 (NIR) and Band 4 (Red).
2. **EVI:** Enhanced Vegetation Index: `2.5 * (NIR - Red) / (NIR + 6 * Red - 7.5 * Blue + 1)`.
3. **SAVI:** Soil-Adjusted Vegetation Index: `1.5 * (NIR - Red) / (NIR + Red + 0.5)`.
4. **NDWI:** Normalized Difference Water Index: `(Green - NIR) / (Green + NIR)` using Band 3 (Green) and Band 8 (NIR).
5. **NDMI:** Normalized Difference Moisture Index: `(NIR - SWIR1) / (NIR + SWIR1)` using Band 8 and Band 11 (SWIR1).
6. **NDRE:** Normalized Difference Red Edge Index: `(NIR - RedEdge) / (NIR + RedEdge)` using Band 8 and Band 5 (Red Edge 1).
7. **GCVI:** Green Chlorophyll Vegetation Index: `(NIR / Green) - 1`.
8. **SAR VH/VV & RVI:** Radar cross-ratio and Radar Vegetation Index when Sentinel-1 synthetic aperture radar observations are ingested.

### B. Distribution Statistics (7 per Index = 63 features)
For each index time series:
- Minimum
- Maximum
- Mean
- Median
- Standard deviation
- 10th percentile
- 90th percentile

### C. Phenological Metrics (10 per Primary Index = 40 features)
Extracted across NDVI, EVI, NDMI, and NDRE:
1. `sos_doy`: Start of Season Day-of-Year
2. `peak_doy`: Peak Day-of-Year
3. `eos_doy`: End of Season Day-of-Year
4. `season_length`: Duration in days from SOS to EOS
5. `amplitude`: Difference between peak and baseline index value
6. `integral`: Area under the smoothed curve (biomass proxy)
7. `greenup_rate`: Slope during vegetative ramp-up
8. `senesce_rate`: Slope during senescence / dry-down
9. `base_value`: Pre-sowing bare soil reflectance
10. `peak_value`: Canopy maximum reflectance

### D. Cross-Index Coupling (2 features)
1. `moisture_to_greenness_ratio`: NDMI peak / NDVI peak (distinguishes irrigated vs dryland).
2. `optical_to_radar_lag`: Delay in days between canopy spectral peak and volumetric backscatter peak.

## 4. Confidence Calibration & Field Inspection Routing

Standard gradient boosted trees output uncalibrated probabilities that tend toward overconfidence. The pipeline incorporates **Isotonic Probability Calibration** on held-out validation folds:
- **ECE Before Calibration:** `0.1108`
- **ECE After Calibration:** `0.0046` (24x calibration improvement)
- **Brier Score:** Improved from `0.0595` to `0.0363`

### Operational Decision Points:
- **Confidence >= 0.947 (95% accuracy operating point):** Model prediction accepted as high-confidence advisory evidence.
- **Confidence < 0.947 OR Margin < 5%:** Model abstains from definitive confirmation. The monitoring record is tagged `NEEDS_FIELD_CHECK` and queued in the Tahsildar inspection dashboard.

## 5. Continuous 15-Day Monitoring Service API

The Python service (`cropsurvey.webapp.periodic_server`) exposes REST endpoints consumed by AgriSurvey AI:

1. `POST /api/analyze?lat={lat}&lon={lon}&start={start}&end={end}&radius_km={radius}&period_days=15`:
   - Enqueues a coordinate monitoring analysis job.
   - Discovers real Sentinel-2 passes, loads aligned sub-grid arrays, builds 15-day composites, and calculates indices.
2. `GET /api/status/{key}`:
   - Polls job progress (`queued`, `searching Sentinel-2 archive`, `reading satellite bands`, `writing results`, `complete`, or `failed`).
3. `GET /api/result/{key}`:
   - Returns the complete multi-period analytical payload including:
     - All 15-day period composites (`label`, `start`, `end`, `mean_ndvi`, `coverage`, `stage`, `health`, `change_since_previous`).
     - Growth summary narrative.
     - Crop prediction rankings with calibrated fit scores.
     - Rendered image URLs (True Color RGB, False Color Infrared, NDVI Color Map).
4. `GET /api/export/{key}.csv`:
   - Streams official tabular CSV for statutory reporting.
